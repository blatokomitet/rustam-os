# RUSTAM OS — Design agent instructions

This project follows RUSTAM DESIGN ENGINE v1.2:
https://github.com/blatokomitet/rustam-design-engine

Read the central repository's `AGENTS.md` and `DESIGN-STANDARD.md` before proposing UI changes (access requires permission because it is private).

Rules:
- Android-first UI; preserve existing application behavior and data.
- Produce 2–3 design directions; obtain explicit approval for each screen before editing UI code.
- Apply principles from Taste Skill (art direction), Impeccable (visual critique), Emil Kowalski Skills (motion/UX), and Playwright (verification). Do not claim third-party skills are installed without checking.
- Respect accessible contrast, 48px touch targets where practical, reduced motion and light/dark modes.
- Do not modify production deployment, credentials, or existing routes without approval.
- After implementation, run relevant tests and report actual results.
