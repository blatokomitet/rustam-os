# RUSTAM OS — AI Playbook

## Цель продукта

Персональный мобильный Life OS: видеть реальный прогресс личности как развитие игрового персонажа. Главный экран — аватар, уровень, XP, прогресс, действия и **шесть жизненных направлений**. Футбольные матчи — отдельная вкладка, а не седьмая сфера. Приложение должно ощущаться как продуманный мобильный продукт, **не как блокнот**.

## Принципы

- **Mobile-first:** основной сценарий — Android. Экраны 320–430 px, safe-area, нижняя навигация, зоны касания от 44 px.
- **Одна итерация — один экран:** сначала изучить существующее решение, затем предложить локальные изменения и проверить на телефоне.
- **Private by design:** пока нет аутентификации и шифрования, сохранять пользовательские записи только локально, не писать персональные подробности в публичный GitHub.
- **Нет выдуманных результатов:** XP, финансовые сводки, активность и данные о здоровье показывать только из реальных записей; демонстрационные значения явно помечать.
- **Управление версиями:** отдельная ветка, черновик PR, никакого merge/deploy без подтверждения владельца.
- **Сохранность:** обратимость действий, резервное копирование и понятная маркировка несинхронизируемых данных.

## 5 проектных подходов

Это **адаптация идей** из публичных Claude Skills. Репозитории-источники не устанавливались в ChatGPT как плагины.

### 1. UI UX Pro Max — система визуального дизайна
Референс: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill

- Визуальный язык: premium-dark, глубокий фон, фиолетово-синие градиенты, тонкие границы, выразительный профиль и геймифицированный прогресс.
- Проверить расположение аватара, читаемость чисел, визуальную иерархию и плотность информации.
- Создавать универсальные CSS-токены; избегать дублирующих компонентов.
- Проверять на реальном телефоне; не выдавать статический макет за проверенный интерфейс.

### 2. Document Skills — документы и архив
Референс: https://github.com/anthropics/skills

- Документы, отчёты, таблицы и вложения должны иметь структурированные метаданные и контролируемые права.
- Экспортировать данные в переносимых форматах.
- Не сохранять приватные документы в публичный репозиторий и не отправлять их в сторонние сервисы без разрешения.

### 3. Humanizer — микрокопирайтинг
Референс: https://github.com/blader/humanizer

- Интерфейс — на русском; переводы можно добавлять позже.
- Текст короткий, конкретный и дружелюбный без искусственного мотивационного пафоса.
- Мотивировать пользователя без давления и без обещаний медицинских, карьерных или финансовых результатов.

### 4. Marketing Skills — презентация и onboarding
Референс: https://github.com/coreyhaines31/marketingskills

- Описывать только реально доступные функции.
- Показывать ценность на основе трёх сценариев: цель → шаг → прогресс; день → действия → XP; сфера → план роста.
- Исследовать полезность онбординга, но не превращать личные данные в маркетинговые метрики без согласия.

### 5. Last30Days — современный опыт и практики
Референс: https://github.com/mvanhorn/last30days-skill

- При внешнем исследовании отделять новые тренды от проверенных практик.
- Оценивать React/vanilla JS/PWA, возможность офлайна, доступность, стоимость и приватность перед решением.
- Датировать исследования и проверять официальную документацию.

## Оценка качества очередного PR

1. Изучены текущие файлы и ограничения.
2. Изменены только нужные части.
3. Данные не попадают в GitHub и наружу.
4. Нет выдуманных метрик.
5. Показаны выполненные проверки и ограничения тестирования.
6. Есть ссылка на PR и инструкции просмотра результата.
