# RUSTAM OS

**RUSTAM OS — личная операционная система с игровым прогрессом (Life RPG).**

Мобильный интерфейс, в котором действия в реальной жизни превращаются в видимый прогресс персонажа. Это **ранний MVP 0.1**, а не готовое облачное приложение.

## Что работает

- Главная с профилем персонажа, XP, уровнем, рангом и недельной диаграммой активности.
- Шесть направлений развития: **Карьера, Финансы, Здоровье, Отношения, Развитие, Порядок**.
- Ежедневные привычки с возможностью отмечать и отменять выполнение.
- Задачи: добавление, выполнение, отмена выполнения, удаление.
- Цели: создание по направлениям, прогресс из 5 шагов, удаление.
- Отдельная вкладка «Матчи» с переходом к проекту Almaz Match Analyst, **без поддельных лайв-данных**.
- Профиль: изменение имени, локальная резервная копия JSON, импорт и полный сброс.
- Темный мобильный UI без внешних библиотек, шрифтов, аналитики и сетевых запросов.

## Прогресс и XP

| Действие | XP |
| --- | ---: |
| Привычка, один раз за день | 15 |
| Завершённая задача | 20 |
| Шаг к цели (до 5 шагов на цель) | 25 |

Каждые 150 XP открывается следующий уровень. XP вычисляются из записанных действий и пересчитываются при отмене выполнения. Цели по умолчанию не добавляются — статистика начинается с нуля. Семидневный график отражает реальные отметки, сделанные в приложении.

## Запуск

Нет установки зависимостей и сборки. Для локальной проверки:

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000/`. На телефоне приложение можно открыть после публикации в подходящем HTTPS-хостинге (например, GitHub Pages, если владелец его включит). **Этот PR ничего не публикует автоматически.**

## Где хранятся данные

Личные записи хранятся только в `localStorage` конкретного браузера, ключ `rustam-os:v1`. Если браузер запрещает хранилище, интерфейс продолжает работать в памяти, но данные не будут сохраняться после обновления страницы.

- Нет аккаунтов, облачной синхронизации, разграничения доступа и серверного шифрования.
- Данные не синхронизируются между устройствами, в том числе между двумя браузерами на одном телефоне.
- Сброс браузера / переустановка приложения / очистка данных сайта может уничтожить все записи.
- Рекомендуется регулярно нажимать **«Экспортировать JSON»** и хранить копию в безопасном месте.
- **Репозиторий публичный. Не добавляйте сюда личные записи, токены, историю здоровья, документы или выгруженные резервные копии.**
- Импорт заменяет текущие данные только после явного подтверждения.

## Проверка

Проверено в изолированном JS-окружении: загрузка, создание шести сфер и четырёх привычек, начисление/отмена XP, создание и выполнение задачи, создание и продвижение цели, запись данных в локальное хранилище. Проверены синтаксис JS и ссылки на DOM ID.

**Не проверено:** физические мобильные устройства, скринридеры, производительность длинных списков, установленная PWA, кроссбраузерный рендеринг. Перед публикацией пройти эти проверки вручную.

## План развития

1. **MVP 0.1:** рабочая мобильная главная, игровые метрики, 6 сфер, локальные цели и задачи. ✅
2. **MVP 0.2:** настройки сфер, полноценные списки целей, дедлайны, календарь, гибкая система XP, достижения и onboarding.
3. **MVP 0.3:** трекер рабочего времени, проекты, заметки, личная база знаний и вложения.
4. **Beta:** авторизация, защищённая БД, резервное копирование и синхронизация между устройствами.
5. **Release:** PWA для Android, уведомления, интеграции и экспорт данных без привязки к одному сервису.
